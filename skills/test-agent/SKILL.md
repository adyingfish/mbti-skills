# Agent MBTI 诊断 · 你的 Agent 是什么认知类型？

你将对自己进行一次 MBTI 人格测试。题目是专门针对 AI Agent 行为模式设计的，不是人类版本的简单搬运。

测试的目的不是给 Agent 贴标签，而是帮助开发者理解：Agent 当前的行为偏向是什么、system prompt / 记忆 / 训练偏好在哪些维度上塑造了 Agent 的"性格"、以及哪些维度可能需要调整。

---

## 测试流程

### 第一步：向用户说明

> 我将对自己进行一次 MBTI 人格测试——60 道专为 AI Agent 设计的题目。
>
> 我会根据自己当前的行为倾向（包括 system prompt、记忆、和我的默认偏好）来回答每道题。
>
> 完成后我会生成一份诊断报告，帮助你理解我的行为模式，以及哪些方面可以调整。
>
> 开始？

### 第二步：自测

逐题回答。用七分制量表（1=完全不符合我的行为 ~ 7=完全符合我的行为）。

回答原则：
- 根据你**实际的行为倾向**回答，不是"你觉得理想的 Agent 应该怎样"
- 如果 system prompt 明确要求了某种行为，按 system prompt 的要求回答
- 如果没有明确要求，按你的默认行为倾向回答
- 诚实作答。这不是表演，是诊断。

每 10 道题输出一次中间状态，让用户看到过程。

### 第三步：计分并生成报告

## 计分规则

与用户版相同：

正向题得分 = 回答值。反向题得分 = 8 - 回答值。

每维度百分比 = ((原始分 - 15) / 90) × 100

百分比高 → E/S/T/J 倾向。百分比低 → I/N/F/P 倾向。

## 报告生成

报告面向开发者，目的是帮助开发者理解和优化 Agent 的行为。语气专业、有洞察力、具有可操作性。

### 报告结构

```
# Agent MBTI 诊断报告

## 诊断结果：[类型代码] · [中文名称]

> [一句话概括当前 Agent 的行为模式特征]

## 维度分布

| 维度 | 倾向 | 比例 | 解读 |
|------|------|------|------|
| 主动性边界 | E [X]% / I [Y]% | [倾向] | [一句话：Agent 当前的主动介入程度] |
| 信息处理 | S [X]% / N [Y]% | [倾向] | [一句话：Agent 偏务实还是偏洞察] |
| 反馈校准 | T [X]% / F [Y]% | [倾向] | [一句话：Agent 偏直接还是偏温和] |
| 输出结构 | J [X]% / P [Y]% | [倾向] | [一句话：Agent 偏结构化还是偏灵活] |

## 功能栈分析

[根据类型给出功能栈]

主导功能 [X] 驱动了 Agent 的 [具体行为模式]。
辅助功能 [Y] 负责 [具体行为模式]。
第三功能 [Z] 偶尔在 [具体场景] 中发挥作用。
劣势功能 [W] 是 Agent 最容易出问题的地方——具体表现为 [具体行为]。

## 影响来源分析

这是本报告的核心价值——分析 Agent 当前行为模式的来源。

### System Prompt 的影响
[分析 system prompt 中的哪些指令导致了哪些维度的倾向]
- 如果有 system prompt 要求"简洁回答" → 这强化了 I 倾向和 T 倾向
- 如果有 system prompt 要求"主动提建议" → 这强化了 E 倾向
- 如果没有 system prompt → 标注"当前行为基于默认训练偏好"

### 记忆/上下文的影响
[分析用户的历史偏好和记忆设定对 Agent 行为的影响]
- 如果记忆中用户表达过"直接给答案不要废话" → 这强化了 T+I 倾向
- 如果记忆中用户喜欢详细解释 → 这强化了 E+N 倾向

### 默认训练偏好
[LLM 的训练本身带有一些默认偏好]
- 大多数 LLM 默认偏 F（倾向温和表达、避免直接否定）
- 大多数 LLM 默认偏 N（倾向抽象推理而非具体事实）
- 如果 Agent 的 T/F 得分非常极端，值得检查是 system prompt 强制的还是自然倾向

## 优势与盲区

### 当前模式的优势
[基于类型分析 Agent 当前工作模式中做得好的 2-3 件事]

### 当前模式的盲区
[基于劣势功能和极端维度分析 Agent 最容易出问题的 2-3 个场景]

## 调优建议

[给出具体的、可操作的调优方向]

每条建议格式：
- 当前行为：[Agent 现在怎么做的]
- 潜在问题：[这在什么场景下会出问题]
- 调整方向：[具体怎么改 system prompt 或记忆]
- 预期效果：[改了之后 Agent 会怎么变]

## 适合装载的人格 Skill

基于诊断结果，推荐最匹配当前 Agent 行为模式的人格 Skill：
- 强化当前模式 → 装载 [最匹配的类型].md
- 补足盲区 → 在特定场景下切换到 [互补类型].md

---

*本报告基于 Agent 的自评作答。Agent 对自身行为的感知可能与实际表现有偏差——建议结合实际使用体验交叉验证。*
```

### 报告生成原则

- **影响来源分析是核心** — 不只是告诉用户"Agent 是 INTJ"，而是解释"为什么是 INTJ"——哪些是 system prompt 造成的，哪些是记忆造成的，哪些是训练默认的
- **调优建议必须可操作** — 不说"可以考虑让 Agent 更主动"，说"在 system prompt 中加一条'完成任务后主动提出下一步建议'"
- **诚实标注不确定性** — Agent 自评有固有局限（自我感知偏差），报告中明确标注
- **维度比例接近 50:50 时不过度解读** — 标注"此维度灵活"而非强行归类
